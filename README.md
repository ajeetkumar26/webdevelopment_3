This project is a responsive single-page website developed using HTML, CSS, and JavaScript. It demonstrates advanced styling through responsive design with media queries, ensuring compatibility across desktop, tablet, and mobile devices. The website includes an interactive JavaScript quiz to enhance user engagement and integrates a public API to fetch and display live data dynamically. The project showcases front-end development skills, including responsive layouts, DOM manipulation, event handling, and API integration, resulting in a modern and interactive web application.
